
# Modelo relacional — SIGEH**PK** = chave primária; **FK** = chave estrangeira; `NULL` = opcional.1. `HOSPITAIS(id_hospital PK, nome, provincia, cidade, endereco, telefone, email, nivel, estado)`2. `SERVICOS(id_servico PK, id_hospital FK → HOSPITAIS, nome, descricao, estado)`3. `CAMAS(id_cama PK, id_hospital FK → HOSPITAIS, id_servico FK → SERVICOS, codigo, tipo, estado)`4. `MEDICAMENTOS(id_medicamento PK, nome, forma, concentracao, unidade_medida)`5. `STOCK_MEDICAMENTOS(id_stock PK, id_hospital FK → HOSPITAIS, id_medicamento FK → MEDICAMENTOS, quantidade, quantidade_reservada, validade_lote, actualizado_em)`6. `BOLSAS_SANGUE(id_bolsa PK, id_hospital FK → HOSPITAIS, grupo_sanguineo, factor_rh, estado, data_colheita, data_validade)`7. `EMERGENCIAS(id_emergencia PK, codigo UNIQUE, data_hora, prioridade, descricao, estado, origem)`8. `NECESSIDADES(id_necessidade PK, id_emergencia FK → EMERGENCIAS, tipo_recurso, descricao, quantidade, prioridade, estado)`9. `PEDIDOS_RECEPCAO(id_pedido PK, id_emergencia FK → EMERGENCIAS, id_hospital FK → HOSPITAIS, data_pedido, estado, observacao)`10. `INTERNAMENTOS(id_internamento PK, id_emergencia FK → EMERGENCIAS, id_hospital FK → HOSPITAIS, id_cama FK → CAMAS, codigo_paciente, data_entrada, data_alta, estado)`11. `ENCAMINHAMENTOS(id_encaminhamento PK, id_emergencia FK → EMERGENCIAS, id_hospital_origem FK → HOSPITAIS NULL, id_hospital_destino FK → HOSPITAIS, data_hora, meio_transporte, estado, observacao)`## Cardinalidades- HOSPITAIS 1:N SERVICOS- HOSPITAIS 1:N CAMAS; SERVICOS 1:N CAMAS- HOSPITAIS 1:N STOCK_MEDICAMENTOS; MEDICAMENTOS 1:N STOCK_MEDICAMENTOS- HOSPITAIS 1:N BOLSAS_SANGUE- EMERGENCIAS 1:N NECESSIDADES- EMERGENCIAS 1:N PEDIDOS_RECEPCAO; HOSPITAIS 1:N PEDIDOS_RECEPCAO- EMERGENCIAS 1:N INTERNAMENTOS; HOSPITAIS 1:N INTERNAMENTOS; CAMAS 1:N INTERNAMENTOS ao longo do tempo- EMERGENCIAS 1:N ENCAMINHAMENTOS; HOSPITAIS 1:N ENCAMINHAMENTOS como origem e destino## IntegridadeTodas as tabelas têm PK; as referências são protegidas por FK. Quantidades não podem ser negativas; quantidade reservada não pode superar a quantidade registada; a validade da bolsa não pode anteceder a colheita. A exclusividade de uma cama para internamentos activos é uma regra operacional que deve ser reforçada com transacções/validação da aplicação numa implementação real.
